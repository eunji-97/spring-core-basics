## 빈 스코프

### 빈 스코프란?
빈 스코프란, 스프링 빈이 생성되고 유지되는 범위를 의미합니다.

1. 싱글톤 스코프
   - 스프링 컨테이너가 시작될 때 생성되고, 컨테이너가 종료될 때까지 유지되는 기본 스코프입니다.
2. 프로토타입 스코프
   - 빈을 요청할 때마다 새로운 인스턴스가 생성되며, 생성과 의존관계 주입까지만 관리합니다.
3. 웹 관련 스코프
   -  request : HTTP 요청 당 하나의 빈을 생성하고 유지합니다.
   - session : HTTP Session 당 하나의 빈을 생성하고 유지합니다.
   - application : ServletContext 단위로 하나의 빈을 생성하고 유지합니다.

### 컴포넌트 스캔 자동 등록
```
@Scope("prototype") // 스코프 지정
@Component // 컴포넌트 스캔 자동 등록
```

### 컴포넌트 스캔 수동 등록
```
@Scope("prototype") // 스코프 지정
@Bean
```

### 프로토타입 스코프와 싱글톤 스코프와 같이 사용 시
싱글톤 내에서 프로토타입 빈을 주입받으면, 싱글톤 빈이 생성될 때 프로토타입 빈도 함께 생성되어 싱글톤 빈이 유지되는 동안 프로토타입 빈도 유지된다.

private ObjectProvider<PrototypeBean> prototypeBeanProvider;  
이렇게 하면 싱글톤 빈이 생성될 때 프로토타입 빈을 주입받는 것이 아니라, 필요할 때마다 프로토타입 빈을 생성하여 사용할 수 있다.(DL)  
**하지만 스프링에 의존적임**

Provider<PrototypeBean> prototypeBeanProvider  
get() 메서드 하나로 심플함  
**의존적이지 않음**
