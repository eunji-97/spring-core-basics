## 기본 순수 자바를 썼을 때의 문제점

``` 
private final MemberRepository memberRepository = new MemoryMemberRepository();
```
메모리에 저장할 지, DB에 저장할 지 명확히 모르는 설계에서 해당 방식은 하나의 방법에 고정되어 있다.
후에 DB에 저장되도록 설계가 변경된다면 서비스 코드를 전면 수정해야 한다.
이는 DIP(의존성 역전 법칙)에 위배된다.

***DIP 의존성 역전 법칙***  
구현체에 의존하지 말고 추상에 의존하라

1. 상위 모듈이 하위 모듈에 의존하지 말 것.
2. 둘다 추상에 의존할 것.
3. 구현체는 추상에 의존할 것.
